# F1 Analytics | F1数据分析平台

一个基于 React + TypeScript 构建的 F1 赛车数据分析网站，使用 OpenF1 和 Jolpica 公开 API 获取实时与历史数据。

## 功能特性

### 数据来源
- **[OpenF1 API](https://openf1.org/)** - 实时与历史遥测数据、圈速、进站、轮胎等
- **[Jolpica API](https://api.jolpi.ca/)** - 车手/车队积分榜、赛事结果

### 页面功能

| 页面 | 功能 |
|------|------|
| 首页 | 赛季概览、近期赛事、车手积分榜快览 |
| 积分榜 | 车手/车队积分柱状图 + 详细排名表 |
| 赛事分析 | 逐圈圈速折线图、排位变化、进站时间、胎策时间线、天气数据 |
| 车手对比 | 多车手圈速对比、扇区时间对比、速度陷阱、综合雷达图 |
| 遥测数据 | 逐圈速度/油门/刹车/档位/RPM曲线，支持双车手对比 |
| 轮胎策略 | 胎策可视化时间线、进站排名、轮胎使用统计 |

## 技术栈

- **前端框架**: React 19 + TypeScript
- **构建工具**: Vite 7
- **样式**: Tailwind CSS 3（暗色主题）
- **图表**: Recharts（折线图/柱状图/雷达图/面积图）
- **路由**: React Router DOM 7
- **HTTP**: Axios

## 本地运行

```bash
npm install
npm run dev
```

访问 http://localhost:5173

## 生产构建

```bash
npm run build
npm run preview
```

## 数据说明

- **实时数据**: 比赛期间自动刷新，历史数据缓存1小时
- **遥测数据**: 每圈约200-400个采样点（原始数据约3.7Hz采样率）
- **支持年份**: 2023年至今

## API 限流说明

OpenF1 API 有请求频率限制，遥测数据（`/car_data`）数据量较大，建议选择特定圈次再加载以避免超时。
